## 官方连接与账号边界

- [ ] 保留各自官方账号、原生登录和官方网络连接；模组房主世界与同一个官方副本实例必须明确区分。
- [ ] 不读取登录凭据，不伪造或补发奖励、背包、物品、任务、解锁或账号进度；这些保持官方处理。
- [ ] 房主世界操作、回放及其官方上报不得泄漏到房客个人官方世界。完成个人世界暂存、隔离、恢复与失败关闭。
- [ ] 未验证游戏版本、原生执行/应用/恢复路径默认停用；必须有实际适配证据，不能通过配置或诊断指令绕过认证。
- [ ] 明确账号处罚及状态异常风险，绝不宣称“官方安全”或“零封号风险”。
- [ ] 保持 V1/V2 公共 ABI；新增能力、阻断原因和诊断经现有世界 JSON 输出。
- [ ] 房间协商协议与功能版本；不兼容者不得进入完整合作状态。
- [ ] 未经真实双客户端验收的能力标为未支持。`full_sync_verified` 在全部必要验收完成前始终为 false。
