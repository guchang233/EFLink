# v1.6.0-dev.2：统一权威架构重构前存档

此版本保留当前人物、队伍、武器和表现适配，以及新增的矿石只读采样与房主资源基线。**矿石受击、破坏和个人资源恢复没有完成同步，完整共享世界尚未实现。**

## 新增代码与证据

- 接入原生矿石身份、模板、耐久、采集状态的游戏线程采样。两个真实客户端各采到 51 个对应矿石，其中 6 个原生耐久不一致，证实旧版本仍独立处理矿石。
- 增加资源生命期、状态版本、房主独占基线、重复命中拒绝、角色更换及场景撤权检查。原生调用成功不等于同步结果确认。
- 增加一次性的只读诊断模块；双端采样后已停用。资料采集没有触发采矿或账号请求。
- 保持 V1/V2 公共 ABI；此前人物表现的观察不等于技能、战斗、投射物、召唤物或世界交互完整验收。

原生操作执行、客机矿石状态应用、受击颤动、破坏、掉落、个人资源恢复均未支持。未完成双客户端端到端验收，`full_sync_verified` 保持 `false`。独立检查和构建成功不能替代这一验收。

## 官方账号与风险

仍使用各自官方账号、原生登录及官方连接。代码不读取登录凭据，不补造物品、奖励、任务或账号进度。两个账号不会因此成为同一个官方副本实例。

**实验模组存在账号处罚及状态异常风险。官方连接不代表官方认可，无法承诺“官方安全”或“零封号风险”。** 尚未证明完整阻止房主世界操作泄漏到客机个人世界；当前存档不能认证这项能力。游戏内菜单显示同样的风险提醒。

此存档用于恢复和对照后续架构重构，不覆盖 `v1.6.0-dev.1`。接下来先移除错误的本地结算路径，统一对象身份、意图验证、原生执行与结果证明、晚加入、换图及个人世界恢复，再以矿石完成首个端到端验收。
