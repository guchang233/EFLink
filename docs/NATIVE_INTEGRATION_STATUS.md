# 原生接入状态与后续实施入口

这是实现清单，不是发行能力清单。当前没有可用的完整权威联机，所有生产玩法认证和 `full_sync_verified` 均为 false。用户离开期间不启动游戏、不安装新 DLL、不要求操作，真实验收统一留到收尾。完整目标见 [ACTIVE_GOAL.md](ACTIVE_GOAL.md)，架构与阶段证据见 [AUTHORITY_REFACTOR.md](AUTHORITY_REFACTOR.md)。

| 链路 | 实际实现 | 仍缺的接入/证据 |
| --- | --- | --- |
| 公共接口与房间传输 | V1/V2 ABI；版本协商；统一对象基线/增量/可靠事件；缺版本闭锁 | 多真实客户端及受控网络、长时验收 |
| 对象身份 | HostWorld/Personal/GuestRoom；同一原生绑定分配器、生命周期、私有 cookie、根保活、关系及状态版本 | GuestRoom 实际对象工厂；各类别的实际原生生命周期读取 |
| 操作受理 | 房主/房客统一 Intent；原生角色归属；一次性执行许可；重复/旧场景/退休分配拒绝；原生回调重入处理 | 原生输入采集与房客四角色的房主端私有演员 |
| 采矿原生执行 | 已编译 `NativeMineEntry`，实际 ObjectPtr 构造、枚举/资源读取、DoOperation；测试自有运行时驱动相同入口 | 真实房客演员；正式技能/命中来源与票据关联；真实游戏 ABI/结果验收 |
| 原生结果 | 统一 Host 只接受已由原生完整观察提交且与对应回调相符的结果；函数返回不能结算 | 生产回调的严格施法实例、攻击者和目标生命周期关联；不能按时间靠近或“只剩一笔”猜归属 |
| 人物/装备/战斗读取 | 正式四槽队伍；原生模板/装备/持握/朝向；怪物 HP/韧性；矿石正式耐久和采集状态 | 人物、装备、技能的房间原生构造/应用；技能/投射物/召唤物/持续效果与控制者适配 |
| 个人实体撤出 | `.86` 编译原生 Hide/Revert 租约候选；管理器/存储根；真实私有句柄观察；异常保留；退出屏障 | 入房流程尚未调用；只覆盖交互物/怪物/NPC，不能提供完整隔离 |
| 官方账号边界 | 保留官方登录/连接；无登录凭据读取；无账号结果补造；所有未验证玩法关闭 | 个人官方消息与房间所有原生角色/技能/异步事件、官方上报的完整隔离 |
| 客机应用 | Replica/WorldHandoff 的基线、版本追赶及“原生观察后放行”规则 | 生产 GuestRoom 原生工厂、应用、反向上报阻断和实际观察；目前没有原生共享世界视图 |
| 离房恢复 | 原生恢复屏障和不可丢弃快照规则；实体撤出租约观察退休片段 | 完整个人世界恢复资料、全部对象/原生事件的恢复与观察；句柄退休不能代替这些证据 |
| 换图和其他玩法 | 旧场景权限撤销、拒绝/加载/缺基线闭锁的统一规则 | 生产原生旅行/初始化/恢复；机关/可破坏物/挑战/Boss/副本的实际适配及验收 |

后续先完成房主端私有原生角色及其技能引用，与全部原生事件/官方上报边界配对。沿同一对象绑定与权威层接采矿操作结果归属，再接客机原生对象工厂、应用和个人恢复，才具备矿石完整端到端候选。采矿调度返回、JSON 状态传输、只读对象数量、实体隐藏句柄和测试夹具均不能代替闭环。

测试自有的 `GameAssembly.dll` 只是微型元数据导出夹具，位于独立测试输出目录。测试通过明确本地路径加载它，不加载安装目录的真实游戏库，不把夹具打包/安装到游戏。离线证据只证明代码在这些契约与故障条件下的行为，不认证实际游戏和官方服务器行为。
